# WPA の File I/O を時系列で 1 イベントずつ表示する

WPA の File I/O は、アクション種別やドライブレターなどでグループ表示されます。絞り込みには便利ですが、Process Monitor のように時系列で確認したい場合には不便です。

列をドラッグして、次の順に並べます。

- Line
- 日時（Start (s)）
- Process
- EventType
- SubType（必要な場合）
- File Path

そのうえで、黄色い縦棒を日時のところまで動かします。Start が完全に一致しない限り、実質的に 1 行 1 イベントの時系列表示になります。
