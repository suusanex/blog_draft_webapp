# File I/O を時系列で1行1イベント表示にする

WPA の File I/O は、アクション種別やドライブレターなどでグループ表示されます。絞り込みには便利ですが、Process Monitor のようにイベントを時系列で追うには不便です。

この記事では File I/O の表示調整だけを扱います。トレースの取得方法や WPA 全体の解説には広げません。

## グループ化が時系列表示を妨げる理由

表示上の黄色い縦棒が、グループ化の境界です。境界の左側にある列はグループ化され、右側にある列は1行1項目で表示されます。

アクション種別やドライブレターなどが左側にあると、それらを単位としたグループ表示になるため、時系列では追いにくくなります。

## 列の並べ替えと境界の移動

列をドラッグし、次の順に並べます。

1. Line
2. Start (s)
3. Process
4. EventType
5. SubType（必要なら）
6. File Path

並べ替えたら、黄色い縦棒を日時の列である `Start (s)` のところまで動かします。Start が完全一致しない限り、実質的に1行1イベントの時系列表示になります。

この基本を知らないだけで、「WPA は使いづらい」と諦めかねません。黄色い縦棒の意味や動かし方を知らなかった人には、まずこの表示を試してほしいです。
