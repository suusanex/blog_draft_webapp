File I/O がアクション種別やドライブレター等でグループ表示されることは絞り込みには便利だが、Process Monitor のような時系列表示には不便。

黄色い縦棒がグループ化の境界で、左側がグループ化され右側が 1 行 1 項目になる。列をドラッグして Line、日時（Start (s)）、Process、EventType（必要なら SubType）、File Path と並べ、境界を日時のところまで動かす。Start が完全一致しない限り、実質的に 1 行 1 イベントの表示になる。

基本を知らないと「WPA は使いづらい」と諦めかねないため、知らなかった人に試してほしい。トレース取得や WPA 全体の解説へは広げない。
